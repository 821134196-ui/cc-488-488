# 社区棋牌室 · 桌台预约与牌具清点系统

登记房间、桌台、预约时段、会员代号、棋类与牌具套装，覆盖计时费用、茶水押金、
开场检查、续时、散场清点、清洁与损坏赔付的完整流程。会员与金额均为演示数据，
零第三方依赖（Python 标准库 + 原生前端）。

## 一条本地启动命令

```bash
./run.sh                 # 重置数据库并生成全套样例（续时冲突/少件/换桌），启动服务
# 等价：python3 -m app.main --reset
```

打开 http://127.0.0.1:8000 。其他参数：

```bash
python3 -m app.main --port 8080      # 指定端口
python3 -m app.main                 # 保留已有数据库启动（无预约时才播种）
python3 -m app.main --no-demo       # 空白目录启动
```

启动后内置进程内调度器每 20 秒执行一次：开场提醒（提前 10 分钟）、到点提醒、
迟到 15 分钟自动释放桌台与牌具。

## 功能与八个视图

| 视图 | 内容 |
|---|---|
| 桌台日历 | 时间轴甘特图，预约条按状态着色，红色"现在"线，点击处理预约 |
| 场地平面图 | 房间按米制 1:132 真实间距绘制，预约条直接贴在桌号下方，点桌新建预约 |
| 计时/续时 | 深色计时卡，**只显示剩余时间**与 ＋30分/＋60分/散场 三个高频操作 |
| 开场清单 | 开场解锁（模拟门锁）、按套装展开固定数量格逐格清点 |
| 散场核验 | 逐格清点 + 茶水泼洒 + 设备故障上报，实际时长向上取整到 30 分钟计费 |
| 清洁队列 | 待清洁 → 清洁中 → 完成；未完成清洁桌台不可预约 |
| 牌具库存 | 套装状态（在库/锁定/使用中/待清洁/待处理）、跨场借据登记与归还 |
| 结算复核 | 赔案认赔/申诉/**负责人减免**、损坏照片、退款幂等复核、事件流水 |

### 关键业务规则

- **双锁**：预约确认同时锁定桌台（`table_locks`）与所选牌具（`kit_locks`），
  区间重叠即拒绝；不同桌台也不能抢同一副牌。开场后 RESERVE 锁升级为 PLAY 锁。
- **并发开场只允许一次**：进程内互斥锁 + IMMEDIATE 事务 + sessions 唯一约束，
  两线程并发 seat 恰有一个成功（有并发测试）。
- **续时必须避开后续预约**：查找桌台/牌具最早的后续预约边界，能续多少续多少
  （截断并提示），紧贴则拒绝并记录"续时冲突"事件。
- **固定数量格清点**：每套牌按应有件数展开固定格位，缺件位置**保留空框**
  （虚线红框）；开场即缺登记争议且散场不重复索赔，散场新缺按棋类单价生成赔案。
- **清洁阻断**：散场结算后桌台 PLAY 锁转 CLEANING 锁、牌具转待清洁；
  清洁完成才释放。维修中的桌台即使清洁完成也不开放，需管理员确认修复。
- **赔付**：少件/损坏走模拟付款网关（幂等键 `pay:<赔案>`）；茶水泼洒从押金
  抵扣；减免必须填写社区负责人批准人。
- **退款幂等**：押金退款幂等键 `refund:<预约>`，网关成功结果永久重放，
  重复点击绝不二次出账；网关 FAILED 不落库、可安全重试。
- **临时换桌**：仅管理员可调，牌具随客转移、旧桌进清洁队列，
  目标桌台时段被占用或维修中时拒绝。
- **损坏照片**：通过页面上传，保存到本地目录 `data/photos/`。

## 演示样例（`./run.sh` 自动生成）

以当前整点为"现在"，用可变时钟回放一条完整故事线：

1. A1 围棋场进行中，结束点紧贴后续预约 → 申请续 60 分钟**被拒（续时冲突）**；
2. A3 象棋场完整开场、散场少一枚红子且茶水泼洒 → 会员**赔付争议**挂起；
3. A5 麻将场因空调异响**临时换桌**到 A6，A5 进入清洁队列；
4. A4 预约超 15 分钟未到场 → **迟到释放**；
5. A2 未来场从共享柜**跨场借件**（借据待归还）；
6. B2 一场历史场次已散场、退款并**完成清洁**，供结算复核展示；
7. 另有 C1/A6/B1 多条未来预约供日历与平面图展示。

## 测试

```bash
python3 -m unittest tests.test_service -v
```

21 个用例覆盖：资源双锁（桌台/牌具/首尾相接）、并发开场、迟到释放、
续时边界（成功/截断/紧贴拒绝/牌具跨桌边界）、清点差异（开场即缺保留空框、
散场新缺索赔、不重复计费、泼洒押金抵扣）、清洁阻断与维修保持、
退款幂等（成功重放、失败可重试、网关只受理一次）、调桌与减免审批。

## 目录结构

```
app/
  db.py         SQLite 表结构与连接（autocommit + 显式 IMMEDIATE 事务）
  service.py    领域服务：预约/双锁/开场/续时/换桌/清点/结算/清洁/赔付
  adapters.py   模拟门锁适配器、模拟付款网关（网关侧幂等）
  scheduler.py  进程内调度：迟到释放与场次提醒
  seed.py       演示目录数据与样例故事线
  server.py     http.server JSON API + 静态文件
  main.py       启动入口
  web/          index.html / styles.css / app.js（原生 JS，无构建）
tests/
  test_service.py
data/
  chessroom.db  SQLite（预约、清点、赔付、流水全部在此）
  photos/       损坏照片本地留存
```
